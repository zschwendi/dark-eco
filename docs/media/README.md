# Dark Eco footage

`dark-eco-vision-pro.gif` is an four-second silent preview from Zach
Schwendiman's own Apple Vision Pro recording of Dark Eco, captured October 26,
2026. It shows experimental Jak 1 third-person immersive gameplay.

The preview uses seconds 20–24 of the supplied recording, scaled to 640 × 360
at 10 frames per second. No upstream OpenGOAL promotional media is used.
It shows a development build, not confirmation that the remaining immersive
rendering issues are resolved.

The original recording is kept outside source control. Do not add game data,
extracted assets, or unrelated personal recordings to this directory.
